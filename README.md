# 인사조직 및 경영체계 진단 설문 (웹 체크형)

웹 주소: https://happykingkong0166.github.io/hrsurvey/

임직원 대상 무기명 진단 설문을 웹에서 응답받고, 응답을 모아 분석하는 단일 HTML 페이지입니다.

## 구성
- **설문 응답**: 8개 진단영역 40문항(5점 척도), 기타 의견, 응답자 정보(직위·직종·근속기간·성별)
- **결과 분석** (소유자 전용): 종합 점수, 영역별 점수와 판정, 강점·개선 TOP 5, 집단별 비교(3명 미만 집단 가림), 문항별 응답 분포, 기타 의견
- **응답 관리** (소유자 전용): 응답 코드 일괄 등록, 응답 목록·삭제, 원자료 및 문항별 분석 CSV 내보내기, 회사명 설정

## 진단영역
| 구분 | 영역 | 문항 |
|---|---|---|
| 1. 경영체계 및 커뮤니케이션 | 경영방침 및 계획 | 1–5 |
| | 경영진 및 상사의 리더십 | 6–10 |
| | 조직운영 및 조직분위기 | 11–15 |
| | 커뮤니케이션 및 업무협조 | 16–20 |
| 2. 급여·복지 / 인사·직무만족 / 조직문화 | 급여 및 복지수준 | 21–25 |
| | 인사 및 교육체계 | 26–30 |
| | 근무의욕 및 직무만족도 | 31–36 |
| | 기업문화 | 37–40 |

판정 기준: 우수 4.0 이상 · 양호 3.5–4.0 · 보통 3.0–3.5 · 개선 필요 3.0 미만

## 응답 자동 수집 (구글 스프레드시트 + 이메일 알림)
- 응답은 구글 스프레드시트 「인사조직 진단 설문 응답」의 `응답` 시트에 한 줄씩 쌓이고, `분석` 시트에서 영역별·문항별 결과가 자동 계산됩니다.
- 수신 프로그램은 `apps-script/Code.gs`입니다. 스프레드시트의 확장 프로그램 → Apps Script에 붙여 넣고 웹 앱(액세스: 모든 사용자)으로 배포합니다.
- 배포 후 받은 웹 앱 주소를 `index.html`의 `SHEET_ENDPOINT`에 넣으면 연결됩니다. 주소가 비어 있거나 전송에 실패하면 응답 코드 방식으로 자동 전환됩니다.

## 참고
응답 저장과 분석 기능은 claude.ai 아티팩트의 데이터 저장 기능을 사용합니다. 이 파일을 브라우저에서 바로 열면 설문 작성과 응답 코드 생성은 되지만, 응답 저장·분석 탭은 나타나지 않습니다.
